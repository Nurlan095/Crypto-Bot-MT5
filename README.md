Чтобы изменить логику бота или интерфейс приложения и выпустить новую версию APK:
1. Сначала всегда сделай `git pull origin main`, чтобы получить актуальные файлы.
2. Внеси нужные изменения:
   - Логика сервера и стратегии: [`server/bot_engine.py`](server/bot_engine.py)
   - Интерфейс Android-приложения и веб-панели: [`android/app/src/main/assets/index.html`](android/app/src/main/assets/index.html) (обязательно скопируй этот же файл в [`server/dashboard.html`](server/dashboard.html), чтобы они были идентичны).
3. Сделай `git add -A && git commit -m "Описание изменений" && git push origin main`.
4. **Что произойдет автоматически через 15 секунд после `git push origin main`:**
   - Сервер `72.56.85.128` автоматически скачает твой коммит из `origin/main`.
   - Если изменился `server/bot_engine.py` или `server/app.py` — сервер обновит их в `/opt/cryptobot/` и перезапустит `cryptobot.service`.
   - Если изменился `android/app/src/main/assets/index.html` или `server/dashboard.html` — сервер **САМ автоматически**:
     1. Увеличит номер версии (`version_code` + 1, например `268` -> `v2.68`) в `/opt/cryptobot/version.json` и пропишет `let localCode = <новый_код>;` внутри HTML.
     2. Упакует новый `assets/index.html` внутрь `/opt/cryptobot/Crypto_Bot_v2_50.apk`, выровняет через `zipalign` и подпишет релизным ключом через `apksigner`!
     3. Когда Нурлан откроет приложение на телефоне, у него **сразу автоматически появится окно «🚀 Доступно обновление! ⬇️ Обновить сейчас»**, которое скачает и установит собранный APK с твоими изменениями!

## 2. Торговые стратегии (Переключаются в приложении)

В приложении во вкладке **«Настройки» -> «Стратегия робота»** (`InpStrategyMode` в [`server/bot_engine.py`](server/bot_engine.py)) доступны 3 стратегии:

1. **⚡ Режим 2 (По умолчанию): «Импульс M15 (Активная)» (`InpStrategyMode = 2`)**
   - Активная внутридневная стратегия: входит по закрытию сильной импульсной свечи `M15` (`body_ratio >= 42%`), пробивающей экстремум предыдущего бара по направлению тренда `H1 EMA(50)`.
   - Не требует многочасового ожидания редкой 10-свечной коробки, поэтому открывает сделки регулярно.
2. **🎯 Режим 1: «Пробой Мандарин (BOS)» (`InpStrategyMode = 1`)**
   - Классическая снайперская стратегия из [`Crypto_Bot_v2_50.mq5`](Crypto_Bot_v2_50.mq5): ждет узкую консолидацию («Коробка Мандарин»), низкую волатильность (`ATR Squeeze`), полнотелую свечу `Marubozu` и пробой структурного уровня `Swing High / Swing Low` (`BOS`).
3. **🔄 Режим 3: «Отскок от уровней (Swing)» (`InpStrategyMode = 3`)**
   - Контртрендовая/канальная стратегия на отбой от локальных границ диапазона последних 8 свечей `M15`.
4. **📐 Режим 4: «Метод Давида Трульяса Вила (Авто-Фибоначчи)» (`InpStrategyMode = 4`)**
   - Авторская система чемпиона мира Давида Трульяса Вила (*HLIT: MACD(12,26,9) + RSI(14) + Volume + Авто-сетка Фибоначчи*):
     - Автоматический поиск импульса (`100% -> 0%`), фильтр дивергенций/моментума `MACD (12, 26, 9)`, скорости `RSI (14)` и объемов (`Volume`).
     - Точечный вход при откате цены от экстремума `0%` и пробое уровня **`23.6%` Фибоначчи**, частичная фиксация («Сейф 50%» + перевод в Безубыток) на уровне **`38.2%` Фибоначчи**, главная цель `Take Profit` на уровне **`61.8%` (`2/3` импульса)**.
   - Также реализован в виде отдельного десктопного советника MQL5 **[`David_Trullas_Fibo_Bot.mq5`](David_Trullas_Fibo_Bot.mq5)** (`David_Trullas_Fibo_Bot.ex5`) с авто-отрисовкой объекта `OBJ_FIBO` на графике, динамическим риском по конфлюэнсу и жесткими дневными лимитами убытка.

### Защита каждой сделки (работает во всех 3 стратегиях и для ручных сделок):
- **Авто-лот от риска (`InpRiskPercent`)**: по умолчанию `3%` от баланса счета с учетом `Stop Loss = 1.5 ATR` и `Take Profit = 3.0 ATR`.
- **«Сейф 50%» (`InpUsePartialClose`)**: при достижении прибыли `+1.5 ATR` робот автоматически закрывает 50% объема сделки в плюс, а остаток переводит в безубыток (`+0.20 ATR`). Также можно нажать кнопку **«💰 Сейф 50%»** или **«🛡 В БУ»** вручную.
- **Защита от дублей**: робот держит не более 1 активной сделки одновременно, чтобы многократное нажатие кнопок не создавало пачку ордеров.

## 3. Структура репозитория

- **[`Crypto_Bot_v2_50.mq5`](Crypto_Bot_v2_50.mq5)** — исходный код торгового советника для десктопного MetaTrader 5 (MQL5).
- **[`David_Trullas_Fibo_Bot.mq5`](David_Trullas_Fibo_Bot.mq5)** (`David_Trullas_Fibo_Bot.ex5`, [`trullas_fibo_btc.ini`](trullas_fibo_btc.ini), [`Start_Trullas_Fibo_Bot_MT5.bat`](Start_Trullas_Fibo_Bot_MT5.bat)) — советник MQL5 по методу Давида Трульяса Вила (MACD + RSI + Volume + Авто-сетка Фибоначчи `23.6%` / `38.2%` / `61.8%`) для BTCUSD на счете `AMarkets-Demo` (`#8112287`).
- **[`server/app.py`](server/app.py)** — FastAPI сервер (`127.0.0.1:8799`, проксируется через Nginx на `https://webrelax.pro/cryptobot/`).
- **[`server/bot_engine.py`](server/bot_engine.py)** — ядро робота 24/7: расчет индикаторов `M15`/`H1`, 3 торговые стратегии, календарь новостей USD, синхронизация с `/opt/mt5/MQL5/Files/mt5_state.json`.
- **[`server/ServerBridge.mq5`](server/ServerBridge.mq5)** (`ServerBridge.ex5`) — MQL5-мост, работающий внутри серверного терминала MetaTrader 5 (`/opt/mt5/terminal64.exe`).
- **[`server/mt5-wine.service`](server/mt5-wine.service)** и **[`server/run_mt5.sh`](server/run_mt5.sh)** — конфигурация `systemd` для круглосуточной работы MT5 под `Wine + Xvfb` на Ubuntu VPS.
- **[`android/`](android/)** — исходный код Android-приложения (`com.nurik.cryptobot`, сборка `Crypto_Bot_v2_50.apk`):
  - [`android/app/src/main/assets/index.html`](android/app/src/main/assets/index.html) — интерфейс из 3 экранов («Терминал», «История», «Настройки»), живой 60 FPS график со сдвигом свечей влево и принудительное автообновление APK.
  - [`android/app/src/main/java/com/nurik/cryptobot/MainActivity.java`](android/app/src/main/java/com/nurik/cryptobot/MainActivity.java) — нативный Android-мост (звуковые оповещения, вибрация, скачивание и установка обновлений APK через `FileProvider`).
- **[`publish_update.ps1`](publish_update.ps1)** — скрипт сборки релизного APK и публикации обновления на сервер `https://webrelax.pro/cryptobot/Crypto_Bot_v2_50.apk`.

## 4. Как добавить новую стратегию (Инструкция для Google Antigravity)

Если нужно добавить 4-ю или 5-ю стратегию:
1. Откройте [`server/bot_engine.py`](server/bot_engine.py) в методе `step_tick()` (блок `strat_mode = int(self.settings.get("InpStrategyMode", 2))`).
2. Добавьте условие `elif strat_mode == 4:` с правилами входа (`self.open_position("BUY", ...)` / `self.open_position("SELL", ...)`).
3. Добавьте пункт `<option value="4">...</option>` в `<select id="s_InpStrategyMode">` в [`android/app/src/main/assets/index.html`](android/app/src/main/assets/index.html) и [`server/dashboard.html`](server/dashboard.html).
